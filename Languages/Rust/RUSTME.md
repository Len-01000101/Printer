<h2>
    &emsp;&emsp;let
</h2>
<code>let</code> is a keyword that allows variables to be assigned. By placing the name you want it to be after, you have successfully created a variable<br>
When paired with the keyword <code>mut</code> that makes the variable mutable <br>

<h2>
    &emsp;&emsp;: String
</h2>
This phrase declares the previously mentioned variable as a <code>String</code> type.

<h2>
    &emsp;&emsp;String::from(___)
</h2>
This phrase turns whatever's inside the parenthises into a String data type
