<h1>
    C lingo:
</h1>
<h2>
    int main(void)
</h2>
In C the main method is an <code>int</code> because of how it handles the return codes, where if it were to <code>return 0;</code> it would finish the script successfully<br>
(Newer verisons of C <code>return 0;</code> implicitly)

<h2>
    printf(___);
</h2>
The <code>printf();</code> stands for print formatted where it takes the text or variables inside the parenthises and outputs it.

<h2>
    &emsp;&emsp;Escape sequences:
</h2>
Escape sequences appear in an abundance across C based languages.<br>
Said escape sequences include <code>\n</code> Enter, <code>\t</code> Tab, and more

<h2>
    &emsp;&emsp;%s
</h2>
<code>%s</code> when printed acts like a <code>for(___)</code> loop, where it repeats until the whole "String" is printed.

<h2>
    &emsp;&emsp;Strings:
</h2>
String objects don't actually exist in C, so instead C has char arrays!<br>
Think of a char array similarly to a list of letters where it's<br>
&emsp;1). 'H'<br>
&emsp;2). 'e'<br>
&emsp;3). 'l'<br>
&emsp;4). 'l'<br>
&emsp;5). 'o'<br><br>
In this list, C prints the individual characters one at a time in order to eventually form a word!
